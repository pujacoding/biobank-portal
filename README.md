# 🧬 AURA Biobank Portal

A full-stack **Biobank & Laboratory Management System** designed to manage biological samples, consent, specimen storage, barcoding, shipments, research requests, and audit activities.

## 🌐 Live Demo

🔗 [Open AURA Biobank Portal](https://biobank-portal.vercel.app)

### Demo Login
**Email:** demo@aura.com

> Demo account is for portfolio demonstration and uses test data only.

## ✨ Key Features

- Sample & Specimen Management
- Consent Verification & Approval
- QR & Barcode Generation
- Inventory & Storage Management
- Shipment Tracking
- Cohort Discovery
- Research Access Requests
- Role-Based Access Control
- Audit Logs

## 🛠️ Tech Stack

**Frontend:** React, Vite, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** PostgreSQL (Neon)  
**Deployment:** Vercel  
**Version Control:** Git & GitHub

## 🔄 Workflow

Sample Registration → Consent → Verification → Processing → 
Barcode → Storage → Research Request → Allocation → Shipment
