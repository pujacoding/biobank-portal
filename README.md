# 🐾 ANIVORA BioBank

*Veterinary Biospecimen Management & Research Platform*

A full-stack veterinary biospecimen management platform designed to manage animal biological samples, owner/custodian authorization, cryo-specimen storage, barcoding, transfers, shipments, research requests, and audit compliance.

## 🌐 Live Access

* 🔬 **Lab Management Portal (Intake, Barcodes, Storage & Transfers):**  
  🔗 [Open ANIVORA Lab Portal](https://biobank-portal.vercel.app/lab)

* 🏛️ **Research & Governance Portal:**  
  🔗 [Open ANIVORA Research Portal](https://biobank-portal.vercel.app)

### Demo Login & Access
* **Lab Portal:** Enter registered email or phone (OTP simulated for testing)
* **Demo Email:** `demo@aura.com` or `admin@aurabiobank.org`

> Demo account is for portfolio demonstration and uses test data only.

## ✨ Key Features

- Sample & Specimen Management
- Consent Verification & Approval
- QR & Barcode Generation
- Inventory & Storage Management
- Shipment Tracking
- Cohort Discovery
- Research Access Requests
- Role-Based Access Control
- Audit Logs

## 🛠️ Tech Stack

**Frontend:** React, Vite, JavaScript  
**Backend:** Node.js, Express.js  
**Database:** PostgreSQL (Neon)  
**Deployment:** Vercel  
**Version Control:** Git & GitHub

## 🔄 Workflow

Sample Registration → Consent → Verification → Processing → 
Barcode → Storage → Research Request → Allocation → Shipment
